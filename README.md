# İnsanlığın Hatalı Talimatları - Mistik Bilgelik Arşivi

İnsan hayatının öğretilmeyen, ancak deneyimle geç öğrenilen kritik anları için zamansız, derin düşünceye dayalı bir dijital arşiv.

## Özellikler

- **Next.js 14 App Router** - SSR/SSG desteği ile performans
- **Tailwind CSS** - Kritik CSS otomasyonu
- **Google Fonts** - Cinzel & Crimson Text
- **Statik Site** - JSON veritabanı, backend yok
- **Responsive Tasarım** - Mobil-first yaklaşım
- **Erişilebilirlik** - ARIA labels, semantic HTML

## Kurulum

```bash
# Projeyi klonlayın
git clone [repo-url]
cd hatali-talimatlar

# Bağımlılıkları yükleyin
npm install

# Geliştirme sunucusunu başlatın
npm run dev

# Tarayıcıda açın
http://localhost:3000
```

## Build ve Deploy

```bash
# Build alın
npm run build

# Vercel'e deploy edin
npx vercel --prod
```

## Klasör Yapısı

```
hatali-talimatlar/
├── src/
│   ├── app/              # Next.js App Router
│   ├── components/       # React components
│   ├── hooks/           # Custom hooks
│   └── lib/             # Data access layer
├── db.json              # Veritabanı
└── public/              # Statik dosyalar
```
